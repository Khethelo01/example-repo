# Shoe Inventory Manager

A Python program for managing shoe stock in a warehouse.

It reads inventory.txt and allows users to view products, add shoes,
search by product code, restock shoes, find the highest quantity,
and calculate each product's stock value.

## How to run

Keep inventory.py and inventory.txt in the same folder.

Open a terminal in that folder and run:

    python inventory.py

Choose an option from the menu.
